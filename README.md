# 🌦️ Weather App
# 📘 Description

A simple and responsive Weather App that lets users search for any city and instantly view the current temperature, weather condition, and an icon representing it — all powered by a live weather API.

# 🚀 Features

• Search any city worldwide
• Displays real-time temperature and condition
• Dynamic weather icons (sun, clouds, rain, etc.)
• Responsive and mobile-friendly layout
• Handles invalid city names gracefully

# 🛠️ Tech Stack

• HTML5 – Structure of the app
• CSS3 – Styling and layout
• JavaScript (Fetch API) – API integration and logic
• OpenWeatherMap API (or similar) – For live weather data

# 💻 Setup

Clone this repository:

git clone https://github.com/AbdulRehman-cell/weatherapp.git


Open index.html in your browser.

Enter a city name and view the weather instantly!
